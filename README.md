# IUTone 反馈

这个仓库只用于收集 IUTone 的问题反馈和功能建议，不包含源代码。

- App Store：<https://apps.apple.com/app/id6824153599>
- 官网：<https://iutone.arborjs.com>

## 如何反馈

在 [Issues](https://github.com/iutone/feedback/issues/new) 中新建一条，尽量写清楚：

- 设备型号和系统版本（如 Apple TV 4K，tvOS 26.1）
- App 版本（「我的」→「账号」中可以看到）
- 问题现象和复现步骤，有截图或录屏更好
- 涉及具体视频或网页时，附上链接

提交前可以先搜索一下，看是否已有相同的问题。
